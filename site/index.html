Copy a Gmail message or thread as clean, compact Markdown—ready to paste into an AI assistant, a doc, chat, or notes.

Install for Chrome Source

How to use

  1. 01 Open a conversation in Gmail
  2. 02 Thread More (⋮) → Copy thread
    Message More (⋮) → Copy message
  3. 03 Paste

Shortcuts: Alt+Shift+T / Alt+Shift+M (on macOS, Alt is Option). Remap in chrome://extensions/shortcuts if needed.

Lean

Subject, From, Date, To, Cc when present—never Bcc. Attachment names, not files.

Readable

Looks like something a careful person wrote. Easy to review, redact, and paste.

Local

No MailContext account, backend, or analytics. Processing stays in the browser.
